Before you start

The useful answers.

Clear expectations about the loader, key, interface, and script.

Where do I get the key?

In the Get AVX section, click Get key to reveal it, then use Copy key. The key is displayed directly on this page; it does not require visiting another site.

Does the download include the entire script?

No. It saves AVX-loader.lua containing the exact loader line shown here. The loader requests the remotely hosted Lua source when executed in a compatible environment.

Does this page run or install anything?

No. It displays information and offers text copying and a loader download. It does not run Roblox code or install an executor.

What if the loader cannot retrieve the script?

The remote file may be private, renamed, removed, or temporarily unavailable. The execution environment also needs to support the HTTP request and loadstring. This website does not verify availability.

How does the 24-hour key memory work?

Where local file access is supported, the script stores an expiration after valid key entry. Reopening does not extend it. The first launch after expiration asks for the key again; an already-running session is not interrupted. It is convenience caching, not secure authentication.

What does ONYX mean?

ONYX is the cosmetic name for AVX’s black-and-red interface. It is not another program or paid tier. Advanced User is a decorative profile subtitle, not verified account privileges.

Are notifications enabled by default?

No. They start off on every execution. Enable them in Settings for the current session; disabling them clears visible and queued alerts.

Does Anti-Fling guarantee immunity?

No. It provides local mitigation. Physics, server behavior, and legitimate high-speed movement can affect results.

Will every feature work everywhere?

No. Feature availability depends on the experience, execution environment, permissions, and supported APIs. The previews are illustrations, not proof of runtime compatibility.
